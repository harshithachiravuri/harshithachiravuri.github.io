2025 – Present

PitchIQ: a multi-agent sales-outreach system

PitchIQ is a sales-outreach application built on LangGraph. Instead of one model writing a message in a single step, several AI agents share the task, and one of them reviews the result.

  • Designed the multi-agent architecture: a research agent gathers information, a drafting agent writes the outreach, and a review agent checks it, with LangGraph orchestrating the hand-offs between them.
  • Implemented retrieval-augmented generation (RAG) with ChromaDB and pgvector, so the agents write from retrieved source data and not from the model's memory alone.
  • Added output guardrails so that responses stay grounded in that source data and within policy before they are used.

How it connects to my research interests: keeping an agent's output tied to its evidence is the same problem, in a business setting, that I want to study for healthcare.

LangGraph, RAG, ChromaDB, pgvector

MCP server layer for autonomous tool discovery and execution

The Model Context Protocol (MCP) is a standard way for AI assistants to connect to outside tools and data. I built an MCP server layer so that an assistant can work with enterprise data tools without each one being wired in by hand.

  • Built the MCP server to expose database and ETL tools, so LLM assistants can discover what is available, select the right tool, and run it on their own across SQL and NoSQL databases and cloud applications.
  • Built FastAPI REST endpoints on top of the connector code, so ETL jobs and MCP tools can also be triggered over HTTP by AI agents and other services.
  • Managed credentials and connector configuration in MongoDB.

How it connects to my research interests: tool discovery and tool use are core parts of agentic AI.

MCP, FastAPI, MongoDB
